# Project Wiki - Full System Demonstration

This folder contains wiki-style documentation for the project.

The purpose of this wiki is to demonstrate that the system is **complete,
integrated, and functional**, and that all components work together
as a single application.

The documentation includes:
- Running the entire system together using `docker-compose`
- User registration and login flows
- File and folder operations performed from the client applications

Each page focuses on a specific part of the system and demonstrates
the required functionality using commands and screenshots.

## Wiki Pages
- [01 – System Overview](01-System-Overview.md)  
  High-level description of the system architecture and components.

- [02 – Run the System](02-Run-The-System.md)  
  Step-by-step instructions for building and running the full system
  using docker-compose.

- [03 – Registration & Login](03-Auth-Flow.md)  
  Demonstration of user registration and authentication.

- [04 – Client File & Folder Operations](04-Client-Operations.md)  
  Demonstration of creating, editing, and deleting files and folders.
