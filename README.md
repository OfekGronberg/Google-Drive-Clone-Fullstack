# Advanced Programming - File Management System

This project implements a multi-component file management system.

The system includes:
- A **File Management Server (C++)** for storing file contents
- A **Web API Server (NodeJS, MVC architecture)** for system logic
- **Client applications**, including a Web client and a React Native (Expo) client
- **MongoDB** for persistent data storage

The project demonstrates a complete end-to-end system, including
authentication, file and folder management, and client-server communication.
